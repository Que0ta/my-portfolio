# 🌐 My Portfolio Website

Welcome to my **personal portfolio website**, made with **Node.js** and **Express**. This website is a digital showcase of who I am, what I do, and the projects I've created. Built for speed, simplicity, and scalability — all running on a lightweight backend.

---

## 🚀 Tech Stack

- **Backend:** [Node.js](https://nodejs.org/) + [Express.js](https://expressjs.com/)
- **Frontend:** HTML5, CSS3, JS
- **Styling:** Custom CSS
- **Assets:** Static files served from `public/` directory

---

## 🧠 Features

✅ Fully responsive and mobile-friendly  
✅ Projects list with detailed descriptions  
✅ Contact form (Mailjet)  
✅ Custom animations
✅ Clean, modular folder structure
